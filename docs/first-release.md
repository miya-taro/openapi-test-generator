# 初版の対応範囲と使い方

対象は「人がUIでAPI仕様・DB対応を設定し、生成された試験を確認した後、自動実行・判定・証跡保存する」用途です。業務上の正解は人が指定し、ツールが推測することはありません。

## 起動

WindowsではGit、Python 3.10以降、Node.js 22.12以降を用意し、コマンドプロンプトで次を実行します。既存フォルダーと分けて取得する例です。

```bat
git clone https://github.com/miya-taro/openapi-test-generator.git openapi-test-generator-v1
cd openapi-test-generator-v1
run-windows.bat
```

依存関係の準備後にブラウザーが開きます。2回目からは同じフォルダーの `run-windows.bat` で起動します。起動中はコマンド画面を開いたままにし、終了時はCtrl+Cを押します。Python・Node.jsは別途必要です。旧インストーラーのexeは初版の配布物ではありません。

## 人が設定することと自動処理

| 人がUIで指定するもの | ツールが行うこと |
|---|---|
| APIのURL・メソッド、入力項目・型・必須・制約、応答仕様 | 代表正常値・境界・型違反・必須欠落等のケース生成、HTTP送信、契約の照合 |
| 認証情報、仕様で許されるエラーステータス | 認証設定を使った送信、定義されたステータス・本文・ヘッダの検証 |
| bodyの「どちらか必須」「両方指定」、項目間の大小条件 | 指定ルールの正常・異常な組み合わせを生成 |
| PostgreSQL / InfluxDB 1.xへの接続、API項目とDB項目の対応 | 明示した検索条件で期待値を取得し、返却内容・件数・重複数を照合 |
| 保存・更新・削除の対象と期待値、変更してはいけない範囲 | API前後のDB状態を取得・比較し、結果を証跡に保存 |
| 生成されたケースの確認・承認 | 承認した定義の実行、Excel・JSON・JUnit・HTMLの出力 |

OpenAPIファイルを用意して取り込む場合も同じ試験処理を使います。画面から保存した拡張設定も保持されます。通常操作で試験コードやSQLを書く必要はありませんが、接続先の検証用データは必要です。必要なデータ不足や取得失敗を合格扱いにはしません。

DBを使わないAPI契約試験も実行できます。GETのJSON bodyにも対応します。具体例は [測定結果GET](measure-get-testing.md) を参照してください。

## 初版の境界

- HTTPのJSON API、PostgreSQL、InfluxDB **1.x / InfluxQL**を対象とします。
- InfluxDBの保存・更新・削除は、固定時刻と全タグで特定する1ポイント。検証用ポイントの準備・後片付けをUIで有効にすれば同じ設定で繰り返し実行できます。既存ポイントは上書きせず停止し、既存DBの復旧は行いません。GETの共通ルール試験では、別途UIで明示した検証用データの準備・後片付けを設定できます。[共通ルール試験](common-rule-tests.md)。[詳細](influxdb-testing.md)
- DBの比較対象は設定した項目・範囲です。未指定のDB全体や任意の業務計算まで正しいとは判定しません。
- DB取得は最大5,000行／ポイント。大量データ・負荷試験、JOIN設定UI、非同期反映待ち、認証トークンの自動更新は対象外です。
- 合成schema等の全組み合わせ生成は保証しません。画面と証跡の「仕様の対応状況」で未生成・一部対応・未対応を確認してください。[詳細](contract-reliability.md)

## 検証済みの範囲

独立した検証用HTTP API、実PostgreSQL、実InfluxDB 1.8.10、Chromiumの実画面を使って、正常系と故障を検出する異常系の両方を確認しています。CIではWindowsの初回起動・再起動も確認します。

- 契約：12操作・162ケース。15種類の故障を検出。
- PostgreSQL：測定結果の抽出、CRUD、変更なし比較、自動生成した異常系のDB副作用を確認。
- InfluxDB：GETの18組み合わせと12種類の故障、異常系20ケース×3種類のDB副作用を確認。保存・更新・削除の4メソッド正常系と13ケースの故障検出、前提不足4ケースの未送信を確認。
- UI：設定→保存→試験準備→確認・承認→実行→結果Excelのダウンロード。失敗ケースの再実行も確認。

再現手順と証跡の説明は [初版検証記録](first-release-validation.md)・[InfluxDB検証記録](influxdb-testing.md) にあります。
利用者の実API・実DBには未接続です。この検証は初版の対応範囲での動作確認であり、個々のAPIの合格や全仕様の網羅を保証するものではありません。

保存・再開、更新方法、依存ライブラリのライセンス確認状況は [運用ガイド](operation-and-licenses.md) を参照してください。
