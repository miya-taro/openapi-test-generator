# 保存・再開・更新と依存ライブラリ

## 設定を保存して再開する

1. API仕様は仕様編集画面、DB対応はDB設定画面で保存する。
2. 「1. 対象を登録」の「このPCに設定を保存」で、接続先・ファイルの場所・対象API・実行設定を保存する。試験準備時にも保存される。
3. アプリを終了し、同じPCで `run-windows.bat` を実行すると設定を復元する。
4. DBパスワードと認証用入力は再確認する。DBパスワードとログイン用認証ボディは接続設定ファイルに保存しない。API定義に正常値の例を保存した場合、その例はファイルに残り、ログイン入力の候補にもなる。
5. 試験を準備し直し、対象・期待値を確認して実行する。APIやDBが前回実行で変更されていれば、同じ結果になるとは限らない。

「プロジェクトを保存」はAPI定義・DB対応ファイルの参照をまとめる機能であり、参照先ファイルのバックアップやDBパスワードの持ち運び機能ではない。別PCでは元ファイルも移し、接続設定を入力する。

### Windowsブラウザー版の保存先

| 内容 | 保存先 |
|---|---|
| 接続先・選択状態等 | `%USERPROFILE%\.openapi_test_gui_settings.json` |
| 読み込んだファイルのコピー | `%LOCALAPPDATA%\OpenApiTestTool\imports` |
| UIで保存したAPI定義・DB対応 | `%LOCALAPPDATA%\OpenApiTestTool\saved` |
| 結果・一時設定 | `%LOCALAPPDATA%\OpenApiTestTool\output` / `temp`。出力先を指定した場合はその場所 |

保存されるファイルは暗号化保管庫ではない。APIの正常値、DB照合値、結果本文には業務データが含まれ得る。認証情報の伏字処理があっても、独自の項目名を含む全秘密情報を検出する保証はない。実行時の接続用一時設定もあるため、共有前にファイルを確認する。

## 更新

アプリを終了し、上記の設定とAPI定義・DB対応・必要な結果をバックアップする。cloneしたフォルダーで次を実行する。

```bat
git pull --ff-only origin master
run-windows.bat
```

ローカル変更や履歴の分岐でpullが止まった場合は、変更を消さずに別フォルダーへcloneする。設定が参照するファイルが以前のフォルダーにある場合は、移動後に選び直す。初回は依存パッケージをダウンロードし、依存定義が同じ2回目以降は再インストールを省略する。画面のビルドは起動時に行う。

旧exeはブラウザー版の更新には使わない。Windows起動の確認はCIの `run-windows.bat -SmokeTest` の初回・再実行で行う。Linux上のブラウザーテストだけではWindows実機での起動確認を代替しない。

## 失敗・未確認の読み方

- **NG**：期待値との不一致。結果サマリーから実行詳細を開いて比較する。
- **ERROR**：接続、認証、設定などで実行できなかった可能性がある。ログを確認する。
- **警告・未確認・未実行**：成功に数えない。全実行ケースが成功しても、仕様の対応状況に残る未対応項目は別に確認する。
- **キャンセル**：送信済みAPIの変更を取り消す保証はない。再実行前にDB状態と後片付け結果を確認する。

## ライセンスの確認状況

2026-10-14時点の検証環境のPythonパッケージメタデータで確認した直接実行依存は次の通り。バージョンの下限指定でインストールするため、別時点の環境は異なる場合がある。

| パッケージ | 確認バージョン | メタデータ上のライセンス |
|---|---|---|
| openpyxl | 3.1.5 | MIT |
| psycopg2-binary | 2.9.13 | LGPL with exceptions |
| requests | 2.34.2 | Apache-2.0 |
| exrex | 0.12.0 | AGPLv3+ |
| jsonschema | 4.26.0 | MIT |
| rfc3339-validator | 0.1.4 | MIT |
| PyYAML | 6.0.3 | MIT |
| influxdb | 5.3.2 | MIT |
| tzdata | 2026.5 | Apache-2.0 |

**すべてがMIT等の許諾型ライセンスという状態ではない。** 正規表現からの値生成に使うexrexはAGPLであり、配布形態や改変・組合せに応じた義務の確認が必要。psycopg2-binaryのLGPLと例外、同梱ライブラリも確認対象になる。この表は法的な利用許可の判断や、推移的依存まで含めた配布用通知文の代わりではない。

UIのnpm依存は `gui-tauri/package-lock.json` の各license欄、開発・探索試験依存はそれぞれのrequirementsを参照する。本リポジトリにはルートLICENSEがなく、リポジトリ自体の再配布条件も未確定。社内の承認なしに「どの会社のPCでも導入・配布できる」とは断定しない。clone起動でも依存ライセンスの条件は変わらない。
