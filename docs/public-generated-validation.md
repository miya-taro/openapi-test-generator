## 対象と期待値の根拠

対象は `GET https://crates.io/api/v1/crates` の `page` と `per_page` です。

- `page`：省略可能な整数、最小値1。
- `per_page`：省略可能な整数、最小値1・最大値100。
- 正常時200、入力不正時400。いずれもJSON本文を検証。

OpenAPIは [公式実装の固定コミット](https://github.com/rust-lang/crates.io/blob/4e0b627fc8fc16391cbe4139f0c5d3f31e91ce47/src/controllers/helpers/pagination.rs) を根拠に人が記述した[部分定義](public-crates-pagination.openapi.json)です。公式配布の完全なOpenAPIではありません。公式実装の `Option<NonZeroU32>`、`minimum = 1`、`MAX_PER_PAGE = 100` と400のエラー処理を参照しています。pageの大きな値にはサービス独自の制限があるため、この部分定義から任意のページが利用可能とは判断できません。

この部分定義から**本アプリの既存ジェネレーターで正常系・異常系を生成し、生成された14件を選別せずすべて実行**しました。応答時間は性能要件に含めていません。

| 試験項目 | 生成・実行件数 | 実測 |
|---|---:|---|
| 最小有効リクエスト | 1 | 200・本文適合 |
| 任意項目の省略 | 2 | 200・本文適合 |
| 最小値1 | 2 | 200・本文適合 |
| 最大値100・中間値50 | 2 | 200・本文適合 |
| 整数に文字列を指定 | 2 | 400・エラー本文適合 |
| null文字列を指定 | 2 | 400・エラー本文適合 |
| 最小値未満の0 | 2 | 400・エラー本文適合 |
| 最大値超過の101 | 1 | 400・エラー本文適合 |
| **合計** | **14（正常7・異常7）** | **全件合格** |

クエリは文字列で送信されるため、ここでのnullはJSONのnullではなく `?page=null` などを意味します。文字列の型不正値は引用符を含む `"abc"` です。正常レスポンスはcrates配列と各要素のid/name、meta.totalの構造・型を確認します。検索結果のDB内容やページ間の完全性はこの試験では検証していません。

異常系の生成値は `4xx` ですが、このOpenAPIは400だけを宣言しているため、404などを合格にはしません。未定義404、誤った200、空のerrors配列、detailの型不正がNGになることは別途オフライン回帰試験でも確認しました。
